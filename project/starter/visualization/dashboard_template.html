How this was built.
  • The 15 game embeddings (1,536-D, OpenAI text-embedding) were read directly from the persistent ChromaDB collection udaplay — no API key needed to read stored vectors.
  • PCA (to 2-D) and the cosine-similarity matrix were computed offline with NumPy. PCA explains only of variance combined — normal for 1,536-D text embeddings, so read the map as relative structure, not absolute axes.
  • The "vector search, live" panel uses each game's stored embedding as the query, so it shows genuine nearest neighbours over the existing 15 items. Embedding an arbitrary new text query would require a live OpenAI key.
